# M3 Trace Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Convert a caller-selected natural Garcia ZIP window into configured
intervals, compare them with independently generated TheaterQ rows, and report
source-versus-converted late-run distributions.

**Architecture:** Independent Python offline tools; no copied reference code and
no changes to the Rust engine. NumPy supplies array arithmetic and the reference
PCG64 random stream. The engine schema remains unchanged; detailed provenance
and diagnostics live in a sidecar manifest, with the recipe in `conversion`.

**Tech Stack:** Python 3.11+, NumPy 2.x, standard-library unittest, existing Rust CI.

**Spec:** [M3 inventory](../../reports/m3-trace-inventory.md), the existing
[trace contract](../../HNG-API.md#trace-files), and the approved follow-up scope:
ZIP/hash/recipe conversion, configured-row comparison, synthetic CI fixtures,
and late-run diagnostics. Outage reconstruction and FIFO behavior remain deferred.

## Global Constraints

- Apache-2.0 SPDX on new source/documents; English public content; no deployment
  identifiers or absolute personal/shared paths. Raw measured data stays external.
- Merge the integrated core branch without rebasing. Install the supplied hook;
  run `scripts/check.sh` before pushing. Keep CI and hook checks identical.
- Source OWD is already ns, not RTT. Missing sequence numbers are missing samples,
  not primary-profile loss. Caller supplies start, duration, offset and seed.
- Preserve trend-based steps (1 ms), 5 ms regression, clipped slope, seeded
  switch times, 1 s floor, 0.05 ms adaptive rows, midpoint values and 1 us rounding.
- No automatic phase/segment selection, canonical-pool claim or HOLD horizon.
  Emit terminal error and no outage/loss intervals. Reject a selected window
  spanning a >0.5 s measurement gap while its reconstruction remains undecided.
- Late diagnostics use full-source median15s baselines anchored to first send,
  strict excess > threshold (default 20 ms), and the source sample cadence.
  Sequence gaps or send gaps >3 times the full-source median interval break runs.
  Compare source and converted values on the same received source samples using
  the same baseline plus the requested offset; do not fit a new baseline to a crop.

## Review Focus

- Bad ZIP/schema, duplicate sequences, negative/overflowing values: reject input.
- Fractional-microsecond boundaries and half-quantum values: match reference ties.
- Full-source RNG/trend state: cropping cannot reset random draws or regression.
- Same-delay route transitions: retain interval boundaries needed by row comparison.
- Missing samples and threshold ties: preserve conservative run breaks and strictness.
