# M1 software I/O and M4 performance implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development for the isolated host I/O task and superpowers:executing-plans for core tools. Test first, keep each logical change in its own commit.

**Goal:** Complete M1 virtual-PMD integrity, then measure M4 software reference costs and memory without claiming physical G2/100G qualification.

**Spec:** The milestone requirements below and `docs/HNG-DESIGN.md`. The I/O milestone requires 32 seeds, 10 million numbered ring packets and independent per-packet checks. The performance milestone requires 100 million operations and the updated per-direction scheduler gate below.

**Architecture:** Test actual PMDs and reuse the production worker/TX path with injected fixture arrival times. Independently compute every surviving identity with finite L2 Q, rational wire service, deterministic selector and stable global sort. Keep software I/O fixtures and runners in the host repo; reports, core microbenchmark and memory calculator live in DPDS-Core.

**Tech stack:** Rust, C/DPDK26.03, Python standard library, Meson; user-local libpcap. No new runtime application dependency.

## Global constraints

- Work only in the existing dedicated WSL2 worktrees. M1 branches hng/m1-io; M4 branches hng/m4-perf start from hng/core. Push only these branches.
- M4 begins only after M1 publication. If M1 is not integrated into hng/core yet, bring only required M1 test-harness commits into the M4 branch and document that dependency.
- M4 execution remains pending the lead's instruction after the M1 handoff. Its accepted update requires one scheduler owner per ingress direction, with independent line states and unchanged semantics. The median gate is 60 ns per owner after splitting, or 30 ns for the previous single owner.
- Never bypass hooks. Inspect the obs worker's hook additions and install by the committed README when available.
- No testbed, system package installation, hugepage/WSL setting or privilege changes. Namespace/veth tests use disposable unprivileged namespaces; unavailable capabilities produce explicit SKIP.
- All numbers are software/WSL2 references. No delay accuracy or physical throughput acceptance on WSL2.

## Review focus

- Every output identity/byte/VLAN mapping, including intentional finite-Q/trace loss, is checked against a separate oracle rather than production deadlines/outcomes.
- At least32 seeds exercise pcap and ring; at least10^7 numbered packets use4 lcores in one net_ring process (total across declared seeds, with counts explicit).
- Real partial PMD returns, delayed handoffs, equal deadlines, both directions and final drain cannot lose/duplicate pointers or create unexpected ordering.
- Histograms measure paired admit+dequeue work and include rational arithmetic; report sampling/resolution, warm-up and overhead rather than hiding it.
- Calculator compares actual allocated object stride/metadata bytes, includes both FIFO allocations and ledger, distinguishes worst-case from p-weighted means, and validates error<=5%.
